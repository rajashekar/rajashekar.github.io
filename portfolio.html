WakeWordDetector

Wake Word Detector is an open-source project aimed at creating a customizable wake word detection system. It takes audio as input and triggers actions upon detecting a predefined wake word sequence. The project encompasses various stages, including data preparation, feature extraction, model training, and inference. It offers multiple inference options, such as using Pyaudio, web sockets, ONNX, TensorFlow.js, and TFLite.

tmux-fzf-copy

tmux-fzf-copy is a tmux plugin that allows users to copy text from the current buffer using fuzzy search with fzf. It provides a quick way to grab and paste any text within the current prompt, inspired by tmux-fzf-url. The plugin enables users to search for words, lines, and quoted text, offering a convenient solution for tasks such as grabbing dynamic pod names or other text where auto-completions are not helpful. Installation via TPM or manually is supported, with customizable keybindings.
