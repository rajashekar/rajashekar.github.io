This project, Reposum, automatically generates a list of repositories within an organization, summarizes each repository using OpenAI, and publishes the summarized information online. WakeWordDetector

Wake Word Detector is an open-source project designed to detect custom wake words from audio input. It enables users to create their own wake word detectors for personal assistant applications. The project includes steps for preparing a labeled dataset, feature extraction, model training and testing, and various inference methods, including Pyaudio, web sockets, ONNX, TensorFlow.js, and TFLite.
