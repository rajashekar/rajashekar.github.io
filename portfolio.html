layoutlens

LayoutLens is an AI-powered tool designed to assist in UI testing. It leverages AI to automatically analyze and validate the layout of user interfaces, identifying potential inconsistencies and errors in design and responsiveness. By automating parts of the testing process, LayoutLens aims to improve the efficiency and accuracy of UI testing, ultimately leading to a better user experience.

diverse_stories

This project utilizes Generative AI to adapt existing stories, primarily from the public domain, to incorporate more diverse characters and cultural contexts. The goal is to enhance the representation within these classic narratives, making them more relatable and relevant to a wider audience. The project focuses on leveraging AI to modify the stories while preserving the original plot and essence.
