reposum

This project, reposum, automates the process of generating a list of repositories within an organization, creating summaries for each using OpenAI, and publishing the information online. It streamlines the task of understanding and documenting a large collection of repositories, providing concise overviews for easy navigation and comprehension.

WakeWordDetector

Wake Word Detector is an open-source project designed to create a custom wake word detection system. It aims to provide a configurable solution that takes audio input and triggers actions upon detecting pre-defined wake words. The project covers all aspects of wake word detection, from data preparation and feature extraction to model training, testing, and deployment. The implementation includes various inference methods using Pyaudio, web sockets, ONNX, TensorFlow.js, and TFLite.
