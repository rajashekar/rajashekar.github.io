incline

Incline is a Python package designed to estimate the trend (or incline) at a specific point within a noisy time series dataset. It addresses the challenge of separating the underlying trend from random fluctuations. The library provides tools to smooth the time series and calculate a local slope, allowing for a more accurate estimation of the trend at a given time. It is particularly useful for analyzing data that is subject to significant noise or variability.
