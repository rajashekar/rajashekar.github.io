WakeWordDetector

WakeWordDetector is an open-source project aimed at creating a custom wake word detector. It allows users to configure specific wake words and trigger actions upon their detection. The project involves data preparation, feature extraction, model training and testing, and supports multiple inference methods, including PyAudio, WebSockets, ONNX, TensorFlow.js, and TFLite, catering to various deployment scenarios. The project draws inspiration from existing wake word detection systems like Mozilla's Firefox Voice and its implementation uses techniques like word alignment and data imbalance correction. The goal is to give users a personalized wake word detection solution.
